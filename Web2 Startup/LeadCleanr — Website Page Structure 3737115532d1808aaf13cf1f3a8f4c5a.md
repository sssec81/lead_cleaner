# LeadCleanr — Website Page Structure

## 1. Website Goal

LeadCleanr should be structured like a focused online utility site.

Main goal:

**One main product + multiple SEO tool pages.**

Each tool page should target one specific search intent.

Example:

- Extract emails from text
- Remove duplicate emails
- Clean email list
- CSV lead cleaner
- Extract emails from CSV

This gives LeadCleanr multiple chances to rank in Google.

---

## `/privacy`

### Privacy Page

Purpose: build trust.

Main message:

**Basic cleaning runs in your browser. We do not store your pasted text or uploaded CSV files.**

Privacy page should explain:

- What data is processed
- Whether files are uploaded
- Whether data is stored
- Browser-first processing
- Analytics/cookies if used later
- Contact email for privacy questions

## `/terms`

Purpose: legal/trust page.

- No spam policy
